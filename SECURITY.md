# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

AegisGateway implements cryptographic API key hashing (SHA-256) and tenant boundary isolation. If you discover a security vulnerability:

1. **Do not create a public GitHub issue.**
2. Email your vulnerability disclosure to `security@aegisgateway.dev` or directly to project maintainers.
3. Include detailed steps to reproduce, impact analysis, and proof-of-concept payloads.
4. We acknowledge receipts within 24 hours and aim to release patches within 72 hours.
